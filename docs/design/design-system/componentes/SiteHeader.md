# SiteHeader

Cabeçalho do site como no manual: logo principal à esquerda, navegação e um botão `primary` à direita, sobre `surface` com linha `border` embaixo.

- No máximo quatro links: “Cartões”, “Ranking”, “Casa”.
- O botão é a ação principal do site: “Criar minha casa”.
- Em telas estreitas a navegação quebra para a linha de baixo.

O consumidor fornece `links`, `cta` e `homeHref`.
