# Ranking

Lista da casa ordenada por pontos, com números tabulares em `pontos` (20px, 600).

- Ordena sozinho do maior para o menor.
- A linha de quem está usando (`me: true`) ganha fundo `surface-alt` e “(você)”.
- Avatares são iniciais sobre `primary`; use foto só se o morador enviou uma.

O consumidor fornece `items` (`name`, `points`, `me`).
