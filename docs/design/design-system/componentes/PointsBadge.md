# PointsBadge

Selo de pontos em lima com números tabulares (tnum), para o placar não pular.

- Use `signed` para ganhos (“+15 pts”) num cartão de tarefa ou num aviso.
- `tone="quiet"` em listas onde muitos selos juntos fariam a lima perder força: a lima é para áreas pequenas.
- Números em formato brasileiro: “1.240 pts”.

O consumidor fornece `value` (número).
