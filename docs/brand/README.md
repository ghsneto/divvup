# Identidade visual do Divvup

Direção escolhida: **Meio a Meio**. Um cartão de tarefa cortado na diagonal, com uma metade já
arrastada para a direita: o swipe virando símbolo.

- **Cores:** Ultramarino `#2f2bd9` (principal) e Lima Ácida `#c9f24d` (aceitar, pontos).
  A lima só aparece sobre o ultramarino ou sobre fundo escuro.
- **Fonte:** Bricolage Grotesque (Google Fonts, OFL), família única para títulos e texto.

## Regras rápidas

- Use os arquivos de `logo/`; nunca redigite nem redesenhe o logotipo.
- Não feche o corte do símbolo e não arraste a metade para a esquerda (página 5 do manual).
- Lima nunca como texto ou ícone sobre fundo claro.
