# Site (divvup.app.br)

Páginas estáticas em pt-BR, sem build: início, termos de uso, política de privacidade e exclusão
de conta (URL pedida pela Play Store: `https://divvup.app.br/excluir-conta/`). O app abre
`/termos` e `/privacidade` (A2, A4, E6).

Publicação no Cloudflare Pages (issue #30): projeto ligado a este repositório, diretório de saída
`site`, sem comando de build, domínio personalizado `divvup.app.br`.

Os textos legais foram escritos para o app como ele funciona hoje. Revise com quem responde
juridicamente pelo app antes de publicar na Play Store.
